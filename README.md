# MAGUS

RPG narrativo solo em terminal, em português, por Diogo Freitas. Este
repositório tem duas versões do jogo lado a lado:

- **[`magus1/`](magus1/)** — o jogo original, como foi entregue, em um
  único arquivo. Mantido praticamente intacto (só uma correção de estouro
  de buffer). Veja `magus1/README.txt`.
- **[`magus2/`](magus2/)** — versão revisada e expandida: código dividido em
  módulos, sem warnings de compilação, os dois personagens protagonistas do
  design original jogáveis (Zauber e Quelle, cada um com as rotas de sair e
  de ficar) e bugs corrigidos. Veja `magus2/README.md`.

Para jogar a versão mais completa, entre em `magus2/`, rode `make` e depois
`./main`.
