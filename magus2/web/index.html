MAGUS 2 // TERMINAL SYSTEM

Magus 2

rpg narrativo
baseado no original de Diogo Freitas
como jogar

Toque ou clique na tela acima para focar o terminal — no celular isso abre o teclado. Digite seu nome e, a partir daí, responda cada pergunta com o número indicado entre parênteses (ex.: 1 = Sim, 2 = Não) e pressione enter. Escolha entre Zauber, o mago, ou Quelle, a elfa, e enfrente a jornada até o Cajado MAGUS.
